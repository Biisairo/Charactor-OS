# Emotion 모듈 스펙

## 1. 목적

캐릭터의 감정 상태를 추적한다. 감정은 대화 중 자유롭게 생겨나고(0~1 스케일), 시간이 지나면 자연스럽게 감소한다.

## 2. 감정 모델

### 구조

```python
{
    "emotion_name": float  # 0.0 ~ 1.0
}
```

- 감정 이름은 **사전 정의 없음**. 대화 중 LLM이 자유롭게 생성
- 예: `{ "행복": 0.8, "피로": 0.3, "설렘": 0.5, "향수": 0.2 }`

### 감소(Decay)

- **턴 기반**: 매 대화 턴마다 모든 감정에 decay_rate 적용
- 공식: `value *= (1 - decay_rate)`
- 기본 decay_rate: 0.1 (매 턴 10% 감소)
- 0.05 이하인 감정은 자동 제거 (노이즈 제거)
- `update()` 호출 시 내부적으로 `apply_decay()`를 먼저 실행

### 예시

```
턴 1: { "행복": 0.8 }                          ← 사용자가 칭찬
턴 2: { "행복": 0.72, "피로": 0.3 }             ← 피로 추가, 행복 감소
턴 3: { "행복": 0.648, "피로": 0.27 }           ← 둘 다 감소
턴 4: { "행복": 0.583, "피로": 0.243 }          ← 계속 감소
...
```

## 3. EmotionModule 클래스

### 인터페이스

```python
class EmotionModule:
    def __init__(self, decay_rate: float = 0.1, save_path: str | None = None):
        """decay_rate와 영속화 경로를 설정한다."""

    def get_state(self) -> dict[str, float]:
        """현재 감정 상태를 반환한다."""

    def to_prompt(self) -> str:
        """감정 상태를 프롬프트 문자열로 변환한다."""

    def update(self, user_input: str, character_response: str, client: Client) -> None:
        """대화를 분석하여 감정 상태를 업데이트한다. (별도 LLM 호출)"""

    def apply_decay(self) -> None:
        """모든 감정에 decay를 적용하고, 0.05 이하를 제거한다."""

    def save(self) -> None:
        """감정 상태를 JSON 파일로 저장한다."""

    def load(self) -> None:
        """JSON 파일에서 감정 상태를 로드한다."""
```

### to_prompt() 출력 형식

```
[현재 감정 상태]
- 행복: 0.8
- 피로: 0.3

이 감정 상태에 맞게 응답의 톤을 조절하세요.
```

감정이 비어있으면:
```
[현재 감정 상태]
특별한 감정 상태 없음
```

### update() LLM 프롬프트

```
다음 대화에서 캐릭터가 느꼈을 감정을 분석하세요.

{이전 대화 맥락 - 흐름과 맥락을 보기 위함}

사용자: {user_input}
캐릭터: {character_response}

현재 감정 상태:
{current_emotions_json}

다음 JSON 형식으로 반환하세요:
{
    "emotions": {
        "감정이름": 0.0~1.0,
        ...
    },
    "remove": ["제거할 감정 이름", ...]
}

규칙:
- 위 대화 맥락을 통해 감정의 흐름을 파악하세요
- 감정 이름은 자유롭게 정하세요 (예: 행복, 슬픔, 분노, 설렘, 피로, 향수 등)
- 값은 0.0에서 1.0 사이
- 이 대화에서 느낀 감정만 포함
- 관련 없는 감정은 포함하지 마세요
- 현재 감정 중 이 대화로 인해 더 이상 유효하지 않은 것은 remove에 포함하세요
- 예: 기분이 나빠졌다면 "행복"을 remove에 추가
```

**참고**: 이전 대화 맥락은 감정의 흐름을 이해하기 위함이며, 실제 감정 분석은 이번 대화를 기반으로 수행한다.

## 4. 영속화

```
memory/emotions.json
{
    "행복": 0.8,
    "피로": 0.3,
    "last_updated": "2026-08-06T10:00:00"
}
```

## 5. 검증 기준

| 검증 | 기준 |
|---|---|
| 감정 추가 | LLM 응답 → 감정 딕셔너리에 반영 |
| 감정 decay | decay_rate 적용 후 수치 확인 |
| 자동 제거 | 0.05 이하 감정이 딕셔너리에서 제거됨 |
| 프롬프트 변환 | 감정 상태가 문자열로 정확히 변환됨 |
| 영속화 | save → load 후 동일 상태 복원 |
